# FRAME - BST V1

Director's Viewfinder web/PWA.

## Test local
La caméra web exige un contexte sécurisé : HTTPS ou localhost.
Sur ordinateur :
    python3 -m http.server 8000
puis ouvrir http://localhost:8000

Sur téléphone : héberger le dossier sur un site HTTPS, puis ouvrir dans Safari/Chrome.

## V1
- caméra téléphone
- sélection de caméra disponible
- calibration par objet de largeur/distance connues
- calibration mémorisée par caméra et orientation
- presets de capteurs cinéma + largeur personnalisable
- focales cinéma
- simulation de champ horizontal
- ratios et frame guides
- grille des tiers / centre
- PWA installable

Les dimensions capteur sont des valeurs de référence et peuvent varier selon le mode d'enregistrement.
